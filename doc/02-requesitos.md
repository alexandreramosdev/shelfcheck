# Requisitos

## Requisitos Funcionais (RF)

### RF001

O sistema deve exibir a conferência do dia.

### RF002

O sistema deve exibir a lista de produtos da conferência.

### RF003

O sistema deve permitir selecionar um produto.

### RF004

O sistema deve permitir informar se o produto foi encontrado na área de venda.

### RF005

O sistema deve permitir informar se o produto foi encontrado no estoque.

### RF006

O sistema deve permitir registrar uma observação.

### RF007

O sistema deve permitir anexar uma foto.

### RF008

O sistema deve salvar a conferência do produto.

### RF009

O sistema deve atualizar automaticamente o progresso da conferência após salvar um produto.

### RF010

O sistema deve retornar para a lista de produtos após salvar a conferência.

## Requisitos Funcionais (RF)

### RNF001

O sistema deve ser desenvolvido seguindo a abordagem Mobile First.

### RNF002

O sistema deve possuir interface responsiva para diferentes tamanhos de tela.

### RNF003

O sistema deve funcionar nos principais navegadores modernos.

### RNF004

O sistema deve armazenar os dados localmente utilizando LocalStorage.

### RNF005

O sistema deve permitir o uso com apenas uma mão em dispositivos móveis.

### RNF006

O sistema deve apresentar uma interface simples e intuitiva, reduzindo a quantidade de interações necessárias durante a conferência.

### RNF007

O sistema deve manter o progresso da conferência salvo mesmo após fechar o navegador.
